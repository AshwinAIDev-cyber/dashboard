# Working preferences

- Before building any app or feature, first check that it can actually do its
  main job on the user's setup: platform rules, paid accounts or entitlements
  (e.g. Apple's Screen Time APIs need a paid developer account), required
  hardware (e.g. a Mac for iOS apps), network/API access. If anything would
  stop it from working, tell the user up front and wait for their go-ahead
  before writing code.
